## Learning Objectives

By the end of this activity, students should be able to:

- Use `if...else if...else` statements for decision-making.
- Use `for` loops to process multiple records.
- Create JavaScript objects and access their properties.
- Create and call regular functions.
- Create and use arrow functions.
- Combine these concepts into a small working JavaScript program.

---

## Problem Scenario

You are developing a simple **Student Performance System**.

The system contains several students. Each student has:

- Name
- Age
- Course
- Grade

Your task is to create a JavaScript program that displays each student's information and determines whether the student is **Excellent**, **Passed**, or **Failed**.

---

# Task 1 – Create Objects and Access Properties
**Time: 10 minutes**

Copy the following starter code into your JavaScript file:

```javascript
const students = [
    {
        name: "Juan",
        age: 18,
        course: "BSIT",
        grade: 92
    },
    {
        name: "Maria",
        age: 19,
        course: "BSCS",
        grade: 85
    },
    {
        name: "Pedro",
        age: 18,
        course: "BSIT",
        grade: 74
    },
    {
        name: "Ana",
        age: 20,
        course: "BSIS",
        grade: 65
    }
];

console.log(students);
```

### Activity

Display the information of the **first student** using object property access.

Do not simply print the entire object.

Use properties such as:

```javascript
students[0].name
students[0].age
students[0].course
students[0].grade
```

### Expected Output

```text
Name: Juan
Age: 18
Course: BSIT
Grade: 92
```

---

# Task 2 – Create a Function with `if` Statements
**Time: 10 minutes**

Create a regular function named `getStatus(grade)`.

Use the following rules:

| Grade | Status |
|---|---|
| 90–100 | Excellent |
| 75–89 | Passed |
| Below 75 | Failed |

### Function Structure

```javascript
function getStatus(grade) {
    // your code here
}
```

Use:

- `if`
- `else if`
- `else`

### Test Your Function

Test the function using:

```javascript
console.log(getStatus(95));
console.log(getStatus(80));
console.log(getStatus(70));
```

### Expected Output

```text
Excellent
Passed
Failed
```

---

# Task 3 – Process Students Using a `for` Loop
**Time: 15 minutes**

Create a `for` loop that processes **every student** in the `students` array.

Use this basic structure:

```javascript
for (let i = 0; i < students.length; i++) {
    // your code here
}
```

Inside the loop, access:

```javascript
students[i].name
students[i].course
students[i].grade
```

Then use:

```javascript
getStatus(students[i].grade)
```

to determine the student's status.

### Expected Output

```text
Juan - BSIT - 92 - Excellent
Maria - BSCS - 85 - Passed
Pedro - BSIT - 74 - Failed
Ana - BSIS - 65 - Failed
```

### Important

Do not manually type the student's status.

The status should come from the `getStatus()` function.

---

# Task 4 – Create an Arrow Function
**Time: 10 minutes**

Create an arrow function named `getMessage`.

It should accept:

- `name`
- `status`

and return a sentence describing the student's performance.

### Function Structure

```javascript
const getMessage = (name, status) => {
    // your code here
};
```

### Example Result

```text
Juan is an Excellent student.
```

For example:

```javascript
console.log(getMessage("Juan", "Excellent"));
```

should produce:

```text
Juan is an Excellent student.
```

# Task 5 – Final Challenge
**Time: 10 minutes**

Now combine everything you have learned into one complete program.

Your final program must:

1. Loop through all students using a `for` loop.
2. Access student properties using object property access.
3. Determine the status using the `getStatus()` regular function.
4. Generate a message using the `getMessage()` arrow function.
5. Use an `if` statement to identify Excellent students.
6. Display all relevant student information.

### Expected Output Format

```text
--------------------
Name: Juan
Course: BSIT
Grade: 92
Status: Excellent
Juan is an Excellent student.
Achievement: Outstanding Performance!

--------------------
Name: Maria
Course: BSCS
Grade: 85
Status: Passed
Maria is a Passed student.

--------------------
Name: Pedro
Course: BSIT
Grade: 74
Status: Failed
Pedro is a Failed student.

--------------------
Name: Ana
Course: BSIS
Grade: 65
Status: Failed
Ana is a Failed student.
```
